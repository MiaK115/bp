# 🩺 Blood Pressure Calculator (BPCalculator)

A simple ASP.NET Core Razor Pages web application that allows users to input their blood pressure values and get categorized feedback based on medical thresholds (Low, Ideal, Pre-High, High).

---

## 🚀 Features

- ✅ Input and validate systolic/diastolic values
- 🧠 Automatic BP category detection
- 📊 Test coverage with detailed reporting
- 🔍 BDD (Behavior-Driven Development) using SpecFlow
- 🛡️ Dependency security audit via GitHub Actions

---

## 🛠️ Technologies

- [.NET 8](https://dotnet.microsoft.com/en-us/)
- ASP.NET Core Razor Pages
- xUnit for unit testing
- SpecFlow for BDD tests
- Coverlet for test coverage
- ReportGenerator for HTML coverage reports
- GitHub Actions for CI/CD
